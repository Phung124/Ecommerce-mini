# Project Documentation

This folder is created to store the documentation for your e-commerce project.

## Tracking Project Structure

To maintain an up-to-date view of the project's framework and files, a snapshot of the project structure is saved in `project_structure.txt`.

**How to update when the project changes:**
Whenever you add, delete, or rename files and folders in your project, you can easily update the structure documentation by double-clicking on the `update_docs.bat` script located in the main root folder of the project. This script will automatically regenerate `project_structure.txt` to reflect the latest changes.
